# H3 图生视频 · 多分镜连贯系统

来源：`MiniMax+-图生视频专用-自动提示词-多分镜连贯系统.txt`（本目录上级）。用于用户上传一张或多张参考图（首帧 / 四宫格 / 序列分镜图）的情形。原始文档为图生视频专用；此处为可直接执行的蒸馏版。

## 核心原则

> 多个分镜不是多个视频，而是**一个完整故事的不同时间切片**。

- 所有分镜共同构成一个完整视频（如 30 秒 = 4 段 × ~7.5 秒；官网/API 单段仍受 4–15 秒限制，长片靠多段生成再剪辑）
- 镜头之间必须满足四个连续性：**时间、动作、空间、人物**
- H3 多图模式的本质：用图片做「电影分镜脚本」，AI 负责补拍摄过程

## 官方三段式（每个分镜的提示词结构）

```text
视频N（@图片N）

【参考素材说明】
@图片N：分镜参考图，锁定当前时间节点的角色状态、构图与场景关系。
图1严格负责人物身份与服装；图2只负责场景布局；……（每张图一个明确职务）

【核心创意】
{该分镜时间段}，{主导风格}。基于整体剧情第N阶段事件：{局部剧情一句话}，镜头风格与前后分镜保持连续。

【画面过程说明】
0-3秒：{景别}，基于@图片N画面结构，{主体当前状态}，镜头{运镜}。
3-6秒：{关键动作变化（延续上一分镜的未完成动作）}。
6-结束：{动作完成或过渡至下一分镜状态，镜头自然收束}。
```

## 系统处理四步

1. **建立全局故事线**：用户没给主题时，从所有分镜图自动推导一条连续叙事（人物在同一空间/同一事件中的时间推进）。
2. **分镜绑定时间轴**（30 秒四宫格示例）：

   | 分镜 | 时间 |
   | --- | --- |
   | 图1 | 0-7s |
   | 图2 | 7-15s |
   | 图3 | 15-22s |
   | 图4 | 22-30s |

3. **一致性锁定**（每个分镜自动补进提示词）：

   ```text
   必须保持与前后分镜同一人物一致性（脸部/体型/服装）
   必须保持空间连续性（同一地点或逻辑延续）
   同一视觉风格、同一叙事事件
   禁止出现额外角色或风格突变
   ```

4. **强连贯规则**：
   - 动作连续：上一镜头的动作**未完成**，下一镜头**接着完成**（走 → 跑 → 停；转头 → 行走 → 回头）
   - 空间连续：不能「瞬移换场」，除非剧情明确转场
   - 时间连续：所有分镜严格组成完整时间线，无空隙无重叠
   - 禁止：突然换衣服、人物消失、场景无逻辑跳跃

## 完整示例（四宫格 30 秒 · 男人在城市中寻找失踪的人）

```text
视频一（@图片1）
【参考素材说明】
@图片1：锁定人物初始状态（站立于街头，情绪不安）。必须保持人物一致性，不得更换身份或风格。
【核心创意】
0-7秒，电影感写实风格。人物站在城市街头，似乎在寻找某人，情绪紧张。
【画面过程说明】
0-3秒：中景，人物（@图片1）站在街头，环顾四周，镜头缓慢推进。
3-7秒：人物开始迈步前行，进入搜索状态，镜头跟随移动。

视频二（@图片2）
【参考素材说明】
@图片2：人物进入城市巷道搜索状态。必须保持与视频一连续性。
【核心创意】
7-15秒，人物进入城市巷道继续寻找目标。
【画面过程说明】
7-10秒：中近景，人物进入巷道，脚步加快。
10-15秒：人物停下观察环境细节，镜头轻微摇动。

视频三（@图片3）
15-22秒，人物发现线索，情绪变化，开始加速行动。

视频四（@图片4）
22-30秒，人物接近目标位置，情绪达到高潮，画面收束。
```

## 与文生视频模式的配合

- 每个分镜段落内部的声音设计、负面约束、运镜规则与文生视频模式完全一致（见 intent-to-storyboard.md 与 h3-format-and-spec.md）。
- API/参考模式：素材职务声明对应 minimax3 六段结构里的 `subject_definitions` + `retention_analysis`（fully_preserved / partially_preserved / attribute_transfer / weak_reference），详见 h3-format-and-spec.md §九-1。
- 首帧/尾帧图 = 图生视频请求；参考图（只要脸/衣服/氛围）= reference-to-video 请求。两类不能混在同一个请求里。
