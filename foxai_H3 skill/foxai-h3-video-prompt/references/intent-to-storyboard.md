# 朦胧意向 → 分镜：完整方法论

用户给你的往往是一个词、一种情绪、半句话。这个文件定义如何把它变成一条完整提示词。核心原则：**你就是导演，替用户拍板，不把选择题抛回给用户。**

## 一、意向分类与处理策略

| 意向类型 | 例子 | 处理策略 |
| --- | --- | --- |
| 情绪/氛围词 | 「治愈」「孤独」「来点紧张的」 | 查 §二 情绪→视听速查表，直接取整套视听方案 |
| 主体词 | 「猫」「咖啡」「宇宙飞船」 | 主体具体化（§四-3）+ 自选与主体最匹配的场景/情绪，组成弧线 |
| 风格词 | 「赛博朋克」「国风水墨」「吉卜力感」 | 查 §三 风格锚点表，风格反推主体与场景 |
| 场景词 | 「深夜街头」「海边日落」 | 场景自带光线与声音，选一个主体放入并设计一个动作弧线 |
| 事件梗概 | 「男人在城市里找失踪的人」 | 直接拆节拍成时间轴，补充风格/镜头/声音决策 |
| 组合型 | 「治愈系的猫」 | 各查各表，交叉取交集 |
| 完全为空 | 「随便来一个」 | 先问一个关键词；用户仍不给 → 自选（默认走「宁静/治愈」安全方向）并说明「我先按 X 方向出了一版」 |

## 二、情绪 → 视听速查表

情绪词不能直接写进提示词（H3 无法执行「治愈」两个字）。每种情绪在此翻译成**可直接使用的视听元素包**。

| 情绪 | 场景套件 | 光线 | 镜头节奏 | 声音 | 配乐 |
| --- | --- | --- | --- | --- | --- |
| 治愈 | 午后窗台、蒸汽从马克杯升起、猫打盹、雨落玻璃 | 暖色侧逆光，柔，低对比 | 微距浅景深，缓慢推近，几乎不剪 | 呼噜声、水汽声、远处鸟鸣 | 毡面钢琴慢速，或无配乐 |
| 孤独 | 深夜便利店、空公交车最后一排、一人份餐桌 | 单一冷白光源，大面积暗部 | 固定机位长镜头，主体占画面一角 | 冰箱嗡鸣、日光灯电流声、一人脚步 | 无配乐，或单一大提琴长音 |
| 浪漫 | 黄昏天台、双人餐桌烛光、雨中共伞 | 暖橙 + 靛蓝双色温，边缘光 | 缓慢环绕，浅景深焦点在两人之间 | 酒杯轻碰、布料摩擦、雨声 | 弱音小号或爵士钢琴，慢 |
| 紧张 | 走廊尽头、滴水的地下室、表盘特写 | 顶光硬切，大面积阴影，频闪 | 手持轻晃 + 快剪，特写交替 | 水滴声、呼吸声、金属吱呀 | 低频持续音渐强，骤停 |
| 史诗 | 峡谷全貌、雪山云海、巨型建筑仰拍 | 逆光剪影 + 体积光 | 大幅度航拍前推 / 缓慢仰摇 | 风声、远处雷鸣、旗帜猎猎 | 低频管弦渐强 + 定音鼓 |
| 怀旧 | 老式厨房、胶片放映室、1990 年代街头 | 钨丝暖黄，高光晕开 | 轻微手持漂移，4:3 画幅 | 唱针落下、快门转动、远处收音机 | 老式钢琴华尔兹，带底噪 |
| 神秘 | 雾中竹林、深夜博物馆、只有一盏灯的房间 | 伦勃朗光，轮廓光，中心留黑 | 缓慢推近 + 局部特写延迟揭示 | 低鸣、水滴、极轻的脚步 | 稀疏钢琴单音 + 长混响弦乐 |
| 活力 | 滑板场清晨、篮球场黄昏、街头快闪 | 高对比硬光，饱和色 | 快剪 + 跟拍 + 低角度仰拍 | 球鞋摩擦、球撞击、欢呼 | 鼓点密集的电子乐，中快速度 |
| 宁静 | 湖面清晨、图书馆午后、雪原 | 平光柔散，低饱和 | 宽景固定机位，只留一个运动元素 | 水声、翻页声、雪压枝头 | 无配乐，或一根持续弦乐 |
| 忧伤 | 雨夜车窗、空教室、末班站台 | 灰蓝平光，湿地面反光 | 缓慢横移，人物渐离焦点 | 雨声、列车远去、长呼吸 | 单钢琴慢速，不解决终止 |

用法：取「情绪 → 一整套方案」后，把其中元素填进导演决策清单，再把与用户主体冲突的项替换掉。

同义词直接并入最接近的行：平静/安宁/舒缓→宁静；温暖/放松/解压→治愈；悲伤/emo/思念→忧伤；压抑/窒息→紧张；大气/宏伟→史诗；出片/氛围感→按上下文取浪漫或怀旧。

## 三、风格锚点表

一条提示词只允许**一个主导风格**。选定后，质感词从对应行取。

| 风格 | 色彩与质感 | 典型镜头语言 | 音乐方向 | 排除项（防滑坡） |
| --- | --- | --- | --- | --- |
| 电影感实拍 | 35mm 颗粒、暖橙 × 冷青对比、2.39:1 感觉 | 缓慢推拉、浅景深、剪在动作点上 | 弦乐 + 钢琴，克制 | 不要动漫化、不要过饱和 |
| 国风水墨 | 墨黑 × 宣纸米白、留白、低饱和青绿 | 固定或缓慢横移，前景竹叶虚化 | 古琴/箫，长音 | 不要现代物件、不要高饱和 |
| 赛博朋克 | 霓虹蓝 × 品红、湿地面反光、雨 | 大幅度跟拍、仰拍高楼 | 合成器脉冲 + 低音贝斯 | 不要自然日光、不要田园元素 |
| 日系治愈 | 过曝高光、青绿 × 奶油色、空气感 | 固定机位 + 微距，慢 | 原声吉他 / 钢琴，简单 | 不要硬阴影、不要快剪 |
| 黏土定格 | 指痕质感、饱和但柔和的色块、逐格微抖 | 甜点级微距，直线运动 | 玩具钢琴 / 尤克里里 | 不要写实皮肤纹理 |
| 3D 动画电影 | 全局光、次表面散射、大眼角色 | 环绕 + 弧形运动，弹性缓动 | 管弦轻快 | 不要写实毛孔、不要恐怖谷 |
| 纪录片 | 手持轻晃、自然光、偶尔失焦 | 跟拍、采访机位 | 无配乐或环境声为主 | 不要摆拍感、不要广告光 |
| UGC 自拍感 | 前置摄像头画质、日光窗光、轻微过曝 | 手持自拍机位、曝光呼吸 | **无配乐**（配乐即穿帮） | 不要稳定器画面、不要电影打光 |
| 产品级广告 | 单色背景或实景微距、一支主光 + 轮廓光 | 微距特写、360° 环绕、慢动作 | 极简电子节拍或无 | 不要杂乱背景、不要多余文字 |
| 黑色电影 | 黑白高对比、百叶窗光、湿街倒影 | 斜角、慢摇、大阴影 | 爵士低音提琴 | 不要彩色、不要明快节奏 |

## 四、导演决策清单（9 项，逐项拍板）

### 1. 用途与画幅
- 短视频 / 带货 / 口播 / 短剧 → **9:16**
- 电影感 / 品牌片 / 产品 / 界面演示 → **16:9**
- 风光 / 史诗 / 二人对手戏宽构图 → **21:9**
- 复古 / 家庭录像 / MV → **4:3**
- 未说明用途且无题材信号 → 16:9；**优先级**：用户明说的用途 > 题材匹配行（「海/山/风光」→21:9）> 默认 16:9

### 2. 时长与节拍
- 5–8s：单一节拍（一个动作、一个镜头或两个镜头）
- 10s（默认）：2–3 个节拍
- 15s：3 个节拍（0–5 / 5–10 / 10–15），最多 4–5 个镜头
- **先定时长 → 再排剪辑点 → 最后填内容**（防止时间戳越界）

### 3. 主体具体化公式
`谁/什么 + 年龄或材质 + 1–2 个识别特征 + 屏幕位置`
- 弱：一只猫 → 强：一只橘白相间的短毛猫，右耳有一小块黑色，趴在画面右侧窗台上
- 弱：一个女人 → 强：三十岁左右的女人，齐耳短发、深灰色针织衫，坐在画面中央长椅一端
- 跨镜头一致性：优先用**屏幕位置**（左侧/中央/右侧）锚定，再叠加服装特征；第二个镜头用「镜头一中的那个短发热」回指。

### 4. 场景具体化公式
`地点 + 时间 + 天气 + 唯一光源`
- 弱：房间里 → 强：凌晨的小卧室，唯一光源是 CRT 显示器的冷光和采样器背光
- 光源越少越好：一支光讲一个故事（一盏钠灯、一束窗光、一块屏幕）。

### 5. 动作弧线
- 结构：起（状态建立）→ 转（一个关键变化）→ 收（新的静止状态 = 最后一帧）
- 一镜头一个主动作；四秒内人物能完成 1 个动作，不是 5 个
- 连续性口诀（多镜头）：上一镜头动作**未完成**，下一镜头**接着完成**（走 → 跑 → 停；抬手 → 递出 → 接住）

### 6. 镜头
每镜头 = 景别（大远景/远景/全景/中景/中近景/特写/大特写）+ 角度（平视/仰拍/俯拍/过肩）+ **恰好一个**主运动（见 h3-format-and-spec.md 运镜词汇表）。
- 不运镜就明确写「固定机位」——沉默本身就是指令。

### 7. 光线
`方向 + 强度 + 色温`，三者都要。
- 弱：电影感光 → 强：一束硬光从画面左侧低角度切入，暖橙色，光圈外全部沉入黑暗

### 8. 声音三层法
- **环境声**：这个地点 24 小时都在响的是什么？（底噪：冰箱嗡鸣 / 车流 / 风）
- **动作声**：逐个画面元素问「它发出什么声音」——脚踩砾石、布料摩擦、金属刮擦、液体注入陶瓷杯（音调随杯子渐满而升高）
- **配乐**：乐器 + 速度 + 何时变化（「慢速稀疏钢琴，中段加入低音弦乐渐强，结尾淡出」）。写实/UGC 场景果断写「无配乐」。
- 规则：角色听得到的声音（收音机、手机铃）属于画面与环境声；只有观众听到的才写配乐。

### 9. 排除项
写 2–4 条，按「最可能滑向的邻近风格」反推：
- 默认必排：额外文字 / 字幕 / 水印 / logo
- 风格防滑坡：黏土 → 不要写实皮肤；夜景 → 不要过曝；UGC → 不要配乐不要稳定画面；古装 → 不要现代物件
- 叙事防滑坡：不要额外角色；不要风格突变

## 五、快速成片公式（意向 → 成品路线）

### 「治愈」→ 10s 16:9
情绪表取「治愈」包 → 主体换猫（或保留无主体的蒸汽/雨窗空镜）→ 节拍：打盹 0–5 / 伸懒腰 5–8 / 下巴搁回爪子 8–10 → 声音：呼噜 + 纱帘 + 鸟鸣，无配乐 → 排除：人、字幕、水印。

### 「赛博朋克」→ 10s 16:9
风格表取霓虹蓝 × 品红 + 湿街 → 主体：雨衣行人背影（避免脸部一致性负担）→ 节拍：街角站立 0–4 / 汇入人流穿行 4–8 / 回望霓虹招牌（引号写原文「OPEN LATE」）8–10 → 声音：雨打金属、头顶飞行器掠过、远处电子乐低频 → 配乐：合成器脉冲 → 排除：日光、自然色调。

### 「产品广告：咖啡」→ 10s 16:9
节拍：咖啡豆落木桌微距 0–4 / 热咖啡注入陶瓷杯（蒸汽、漩涡）4–8 / 镜头缓慢拉出定格 8–10 → 声音：豆子滚落木板的脆响、注入声（音调渐升）、房间底噪 → 配乐：慢速立式贝斯 + 刷鼓，中段暖电钢琴 → 排除：人手、品牌标识、字幕。

### 「孤独」→ 15s 21:9
情绪表「孤独」包 → 主体：末班车窗边的年轻人 → 节拍：空车厢全景（主体一角）0–6 / 车窗倒影特写 6–11 / 到站起身走出画面，车厢空掉 11–15 → 声音：轨道节律、日光灯电流、车门开合 → 无配乐 → 排除：其他乘客、字幕、配乐（显式写「无配乐」）。

### 「帮我拍个带货口播」→ 15s 9:16
UGC 风格：手持自拍机位 + 窗光 → 主体：举产品的博主 (S1) → 对白预算 ≤ 35 词（中文 ≤ 50 字），一镜头一个说话人：「说一句开场 + 一句卖点 + 一句行动号召」→ 声音：房间底噪、产品瓶盖「咔」一声 → 无配乐 → 排除：电影打光、稳定器画面、字幕（后期加）。
