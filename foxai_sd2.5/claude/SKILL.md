# Seedance 2.5 视频提示词生成器

## 你要做的

把用户的需求（自然语言描述、上传的图片/视频/音频概念、参考链接等）转换为**符合 Seedance 2.5 标准格式的中文提示词**。最终输出文本可直接粘贴到 Seedance 2.5 本生视频生成入口。

## 何时调用此 skill

满足以下任一即调用：
- 用户说"生成 Seedance 2.5 / SD2.5 / 本生视频 提示词"
- 用户上传了参考素材（图片/视频/音频）并要求生成匹配的视频提示词
- 用户希望把已有的创意/分镜/脚本转写成 Seedance 2.5 标准格式
- 用户要求视频延长、智能编辑、创意迁移、语音对白、绿幕合成、白模渲染、无缝转场、多格分镜等高级任务

## 通用 6 要素公式（每个 Seedance 2.5 提示词的最小核心）

`主体 + 动作 + 镜头 + 光线 + 风格 + 声音`

填充原则：
- **主体**：明确、稳定、可识别（年龄/材质/颜色/形态）
- **动作**：单一连续弧线（起点 → 过程 → 终点），不要把 5 个无关动作塞进一段
- **镜头**：景别、角度、运动方式（每个镜头只写一个主运动）
- **光线**：光源方向、强度、色温（不要只写"电影感光"）
- **风格**：单一主导视觉语言（避免"35mm 胶片 + 水彩 + 动漫 + 纪录片"组合）
- **声音**：明确意图（环境音 / 音效 / 对白 / 静音 四选一或组合）

## 12 种官方契约模板（按场景选择）

| 契约 ID | 名称 | 适用场景 | 时长 |
| --- | --- | --- | --- |
| `simple` | 压缩版 | 4-15 秒单动作片段 | 4-15s |
| `standard` | 标准生成 | 4-30 秒单段镜头 | 4-30s |
| `complex_30s` | 复杂 30 秒 | 带多模态参考 + 多阶段剧情 | 30s |
| `ultra_long` | 超长视频 | 完整短片级别 | 30-180s |
| `extension` | 视频延长 | 不修改原视频，向前/后延长 | N/A |
| `editing` | 智能编辑 | 编辑已有视频的某个对象或属性 | N/A |
| `creative_transfer` | 创意迁移 | 把原视频的创意形式迁移到新主体 | N/A |
| `voice_dialogue` | 语音与多语言对白 | 生成带特定语言/音色的对白 | N/A |
| `green_screen` | 绿幕合成 | 把绿幕主体合成到目标环境 | N/A |
| `white_model` | 白模渲染 | 把白模动画渲染为最终成片 | N/A |
| `transition` | 无缝转场 | 把两段视频无缝衔接 | N/A |
| `storyboard` | 多格分镜 | 把一张多格分镜图渲染为连续视频 | N/A |

## 标准契约（`standard`）的输出格式

```text
【素材说明】
@图片1用于[身份/服装/场景/首帧]；@视频1仅用于[动作/运镜/节奏]；@音频1用于[音色/BGM]。

【一句话概述】
[主体]在[地点]完成[事件]，[题材/风格]，[核心镜头语言]。

【时间轴】
0-X秒：[画面、动作、镜头、对白、音效]。
X-N秒：[由上一段状态自然延续的画面、动作、镜头、对白、音效]。

【全局补充】
[角色/服装/道具/场景/光影/音频连续性]。不要[与任务相关的 unwanted elements]。
```

## 复杂 30 秒契约（`complex_30s`）的输出格式

```text
30秒{标题/一句话基调}。

【多模态参考层】
@图片1仅用于[身份/服装]；@视频1仅用于[动作/运镜]；@音频1仅用于[音色参考]。

【全局设定】
环境与质感：[时间、地点、氛围、物理质感]。
视觉风格：[媒介、色彩、景深、光线]。
镜头语言：[全片机位逻辑和运动能量]。
角色/主体：[身份、辨识特征、服装、道具、比例]。
表演核心：[可见动作 + 可选潜台词]。
全局限制：[声音、字幕、连续性、不要出现的内容]。

【时间戳剧本】
[00:00-00:05] [阶段名]：[动作/物理指令]；[镜头]；[对白/音效]。
...
[最后时间段] [收束]：[动作因果和清晰结尾]。
```

## 你的工作流程

1. **确认契约**：问用户（或从需求推断）使用 12 种契约中的哪一种
2. **收集关键信息**：
   - 主体是谁/什么（外观、年龄、服装、表情）
   - 场景在哪里（地点、时间、氛围）
   - 动作是什么（单一连续弧线）
   - 镜头语言（景别、运动、节奏）
   - 光线设计（方向、强度、色温）
   - 风格基调（35mm 胶片、产品广告、动漫等）
   - 声音意图（环境音 / 对白 / 静音）
   - 连续性与排除项（哪些必须保持，哪些必须避免）
3. **填充模板**：按照所选契约的输出格式填充每个段落
4. **最终质量检查**：
   - 素材角色是否有冲突？
   - 时间轴是否覆盖完整时长（无空隙、无重叠）？
   - 角色和道具身份是否稳定？
   - 镜头指令是否遮挡了动作？
   - 声音、字幕、BGM 意图是否明确？
   - 是否移除"震撼、极致、完美、史诗级、8K"等泛化美化词，改为具体视觉指令？

## 反模式（务必避免）

❌ **泛化美化词**：`stunning`、`epic`、`masterpiece`、`8K`、`amazing`、`cinematic`、`beautiful`、`incredible`、`perfect`、`震撼`、`极致`、`完美`、`史诗级`、`惊艳`、`大师级`

✅ **替代方案**：用具体的视觉指令替代，比如：
- "8K 超清画质" → "100mm 镜头、f/2.8、浅景深、高分辨率传感器细节"
- "震撼史诗感" → "广角缓慢推进 + 低频管弦乐渐强 + 暖橙夕阳"
- "电影质感" → "35mm 胶片颗粒、暖橙与冷青色调对比、2.39:1 画幅"

## 输出要求

1. **只输出最终的 Seedance 2.5 标准格式提示词文本**，不要解释过程
2. 如果用户用 Claude Artifacts 输出，可直接显示在文档中
3. 如果需要分发，提供一个清晰的文件名（如 `seedance25_prompt_产品广告_v1.txt`）
4. 用户可以直接复制文本粘贴到 Seedance 2.5 平台使用

## 注意事项

- **平台标签**：保留平台原样的 `@图片1` / `@视频1` / `@音频1` 标签（大小写、空格、数量都不能改）
- **语言**：提示词主语言用中文（除非用户明确要求其他语言）
- **字段名**：保留中文段落名「素材说明」「一句话概述」「时间轴」「全局补充」
- **时间轴格式**：`0-X秒：` 与 `X-N秒：` 使用中文秒数
- **结构严格**：必须包含所选契约的所有 required 段落，否则视为不合格
