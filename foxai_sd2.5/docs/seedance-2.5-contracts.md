# Seedance 2.5 提示词契约参考

数据来源：字节跳动 Seedance 2.5 官方文档与社区最佳实践。
该文档是 `foxai_sd25_video` 插件使用的标准格式参考。

## 12 种官方契约模板

### 1. `simple` — 压缩版（4-15 秒）

**适用**：单动作简单片段，4-15 秒内的短视频。

**输出格式**：
```
[主体和场景]。[可见动作与终点]。镜头：[单一运动]。光线：[光源]。声音：[环境/音效/对白/静音]。保持[关键不变量]；不要[关键排除项]。
```

**示例**：
```
一位年轻女性走在雨后的东京街道上。她转身面向镜头微笑，雨水从伞尖滴落。镜头：中景、平视、缓慢推进。光线：傍晚侧逆光，暖橙色天空。声音：雨滴声与远处的车流。保持她的面部特征与服装不变；不要文字或字幕。
```

### 2. `standard` — 标准生成（4-30 秒）

**适用**：最常用的单段镜头提示词模板。

**输出格式**：
```text
【素材说明】
@图片1用于[身份/服装/场景/首帧]；@视频1仅用于[动作/运镜/节奏]；@音频1用于[音色/BGM]。

【一句话概述】
[主体]在[地点]完成[事件]，[题材/风格]，[核心镜头语言]。

【时间轴】
0-X秒：[画面、动作、镜头、对白、音效]。
X-N秒：[由上一段状态自然延续的画面、动作、镜头、对白、音效]。

【全局补充】
[角色/服装/道具/场景/光影/音频连续性]。不要[与任务相关的 unwanted elements]。
```

### 3. `complex_30s` — 复杂 30 秒生成

**适用**：带多模态参考和多阶段剧情的 30 秒视频。

**输出格式**：
```text
30秒{标题/一句话基调}。

【多模态参考层】
@图片1仅用于[身份/服装]；@视频1仅用于[动作/运镜]；@音频1仅用于[音色参考]。

【全局设定】
环境与质感：[时间、地点、氛围、物理质感]。
视觉风格：[媒介、色彩、景深、光线]。
镜头语言：[全片机位逻辑和运动能量]。
角色/主体：[身份、辨识特征、服装、道具、比例]。
表演核心：[可见动作 + 可选潜台词]。
全局限制：[声音、字幕、连续性、不要出现的内容]。

【时间戳剧本】
[00:00-00:05] [阶段名]：[动作/物理指令]；[镜头]；[对白/音效]。
...
[最后时间段] [收束]：[动作因果和清晰结尾]。
```

### 4. `ultra_long` — 超长视频（30-180 秒）

**适用**：完整短片级别。

**输出格式**：
```text
全片时长{XX秒}，画幅{比例}，分辨率{480p/720p}，{一句话类型与基调}。

【素材与角色 Bible】
[角色身份、面孔、发型、服装、道具所有权、声音和参考范围]。

【故事概述】
[开端 → 发展 → 转折 → 高潮 → 结尾]。

【全局连续性】
[风格、时间/天气、场景地理、角色不变量、音频设计、禁止项]。

[00:00-00:20] 第一幕：[本段叙事目标、动作因果、镜头和声音]。
...
[最后时间段]：[回收主线并形成明确结尾]。
```

### 5. `extension` — 视频延长

**适用**：不修改原视频，向前/后延长。

**输出格式**：
```text
参考@视频1，向{前/后}延长{新增秒数}秒。提示词仅作用于新增部分，原视频保持不变。
交接状态：@视频1的{首/尾}帧中，[角色位置、朝向、动作动量、镜头运动、光线、声音]。
0-X秒：[无切镜地延续动作与运镜]。
X-N秒：[新增事件和收束]。
保持@视频1的[身份、服装、场景地理、光照、色调、声音]一致；禁止生硬切镜、位置重置或物体凭空出现。
```

### 6. `editing` — 智能编辑

**适用**：编辑已有视频的某个对象或属性。

**输出格式**：
```text
编辑@视频1。
修改对象：[具体对象]。
变化：[原状态A] → [目标状态B]。
生效时段：[全片 / X-Y秒 / 从第X秒逐渐出现]。
保持不变：[人物、动作、镜头、背景、字幕、声音、构图、光影中不应被改动的部分]。
[被删除区域如何补全 / 新元素如何匹配透视、光照和材质]。
```

### 7. `creative_transfer` — 创意迁移

**适用**：把原视频的创意形式迁移到新主体或新场景。

**输出格式**：
```text
参考@视频1的[创意形式、镜头轨迹、节奏、情绪、喜剧机制、转场逻辑]，
将主体替换/重构为@图片1的[新主体]，场景为[新场景]。
必须保留：[选定的创意内核]。
不要迁移：[原人物、原背景、品牌、水印、无关道具或原音轨]。
保持新主体的身份、外形和场景逻辑稳定。
```

### 8. `voice_dialogue` — 语音与多语言对白

**适用**：生成带特定语言和音色的对白。

**输出格式**：
```text
角色[名称/@图片N]使用[目标语言]说："[exact line]"。
音色参考@音频1，仅参考[声线、年龄感、语流、情绪]，不要把参考音频当作BGM。
演绎：[低沉悬疑/克制悲伤/活泼带货等]；断句：[说明]；口型与目标语言发音同步。
字幕：[无字幕 / 仅显示目标语言字幕，准确文本为"…"]。
```

### 9. `green_screen` — 绿幕合成

**适用**：把绿幕主体合成到目标环境。

**输出格式**：
```text
将@视频1的绿幕前景主体合成到@图片1/@视频2的[目标环境]。
保留前景主体的身份、动作和时序；移除全部绿色背景、绿色溢色和边缘残影。
匹配目标环境的透视、机位运动、光线方向、色温、接触阴影、景深和环境反射。
[新增交互与时间点]。禁止出现贴片感、边缘闪烁或背景漂移。
```

### 10. `white_model` — 白模渲染

**适用**：把白模动画渲染为最终成片。

**输出格式**：
```text
@视频1是{粗/细颗粒}白模，只参考[动作、动线、运镜、角色站位、遮挡、光影变化、切镜节奏]。
映射：[颜色/形状模型] → @图片1的[角色]；[...] → @图片2的[道具/场景]。
[按时间线描述剧情、完整肢体动作和互动因果]。
场景：[文字或@图片N]。最终风格/材质/光影：[要求]。
不要保留白模材质、灰色背景、辅助线或未指定模型。
```

### 11. `transition` — 无缝转场

**适用**：把两段视频无缝衔接。

**输出格式**：
```text
将@视频1和@视频2无缝衔接，不修改两段原视频本身。
连接设计：@视频1尾帧的[锚点]以[方向/速度]运动并[遮挡/填满/变形]画面；过渡为@视频2首帧的[对应锚点]。
在连接点保持锚点的形状、位置、尺寸、运动方向、速度、光线或色彩连续。
情绪从[A]过渡到[B]。生成的桥接段不得出现黑屏、跳帧、硬切、闪烁、文字或主体突变。
```

### 12. `storyboard` — 多格分镜

**适用**：把一张多格分镜图渲染为连续视频。

**输出格式**：
```text
@图片1是一张包含[N]个连续镜头的分镜图，每一格代表[完整镜头/人物/场景]，阅读顺序为[顺序]。
角色映射：分镜中的[A]对应@图片2的[角色]；[B]对应@图片3。
[按镜头描述时间线和动作因果]。
最终风格/材质：[要求]。
保持分镜的镜头构图、人物比例与镜头运动一致；不要改变分镜顺序。
```

## 通用 6 要素公式

`主体 + 动作 + 镜头 + 光线 + 风格 + 声音`

### 主体

- 明确、稳定、可识别
- 描述外观细节（年龄/材质/颜色/形态）
- 避免"一个人"、"一个产品"等模糊描述

### 动作

- 单一连续弧线（起点 → 过程 → 终点）
- 不要把 5 个无关动作塞进一段
- 给出"做什么、怎么做、做到什么程度"

### 镜头

- 景别：wide shot, medium shot, close-up, macro close-up
- 角度：eye-level, low angle, overhead, three-quarter
- 运动：slow push-in, dolly-out, pan left, tracking shot, orbit, crane up, locked-off

### 光线

- 光源方向（key/fill/rim/back）
- 强度（soft/hard）
- 色温（warm/cool/neutral）
- 阴影方向

### 风格

- 单一主导的视觉语言
- 避免组合"35mm 胶片 + 水彩 + 动漫 + 纪录片"
- 选一种风格并贯彻

### 声音

- 环境音（ambience）
- 音效（SFX）
- 对白（dialogue）
- 静音（silence）
- 或音乐（music）

## 反模式（务必避免）

❌ **泛化美化词**：
- `stunning`, `epic`, `masterpiece`, `8K`, `amazing`
- `cinematic`, `beautiful`, `incredible`, `perfect`
- `震撼`, `极致`, `完美`, `史诗级`, `惊艳`, `大师级`

✅ **替代方案**：
- "8K 超清画质" → "100mm 镜头、f/2.8、浅景深、高分辨率传感器细节"
- "震撼史诗感" → "广角缓慢推进 + 低频管弦乐渐强 + 暖橙夕阳"
- "电影质感" → "35mm 胶片颗粒、暖橙与冷青色调对比、2.39:1 画幅"

## 平台标签规范

保留平台原样的标签，**不能**修改大小写、空格或数量：

- `@图片1` / `@图片2` / ...
- `@视频1` / `@视频2` / ...
- `@音频1` / `@音频2` / ...

每个标签的用途必须明确：
- `@图片1用于[身份/服装/场景/首帧]`：从图片中提取什么
- `@视频1仅用于[动作/运镜/节奏]`：从视频中提取什么（不提取人物、场景、品牌等）
