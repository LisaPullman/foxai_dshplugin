DeepSeek Harness 是什么:给你的 AI 装上一整套“工程手脚”的乐高底座

官方开源的 Agent 运行时，一切皆插件的乐高式 AI 工程框架

一句话认识 DeepSeek Harness

  • DeepSeek 官方 2026-08-13 开源的 Agent 运行时，命令行简称 dsh。
  • 比喻：给只会说话的大脑装上外骨骼，让模型真正在你电脑里干活。
  • 负责会话、工具调用、文件读写、命令执行和多轮循环。
  • MIT 协议免费可商用，TypeScript 编写，需 Node.js 22+。

核心哲学：一切皆插件

  • 框架内没有不可改动的硬编码内核。
  • 模型适配器、工具注册表、会话日志、终端执行、智能体循环都是插件。
  • 可以自由挂载、替换插件，像乐高一样拼装。
  • 社区称之为“Agent 界的 Android”。

底层容器：Cordis

  • Cordis 是支撑插件拼装的容器框架。
  • 提供依赖注入：插件间互相提供和获取服务。
  • 类型化事件：在生命周期关键点挂接自定义逻辑。
  • 可逆副作用：插件卸载时自动还原其改动。
  • 比喻：乐高底板，规定积木卡口尺寸，让插件严丝合缝。

三种启动形态

  • Web 形态：npx -y @deepseek-ai/dsh web 打开浏览器图形界面（127.0.0.1:3080）。
  • Headless 形态：dsh --profile headless “任务” 跑完输出结果后退出，适合脚本自动化。
  • 自定义形态：可创建终端界面、桌面应用、机器人等。

关键概念：Profile 与 Bundle

  • Profile（档案）：可启动形态，列出叠放的组合包、插件和用户补丁层。
  • Bundle（组合包）：插件配置的分发格式，像一盒标准积木。
  • 都在各自 package.json 中用 dsh 字段声明。
  • 多层补丁按顺序叠加，后补丁可覆盖前面配置。
  • 命令 dsh --profile web --dump-config 可打印完整配置树。

核心能力一览

  • 模型接入：对接 DeepSeek V4 系列，支持不同推理档位。
  • 工具：写文件、执行终端命令、搜索、调用技能，带把关流水线。
  • 会话：只追加日志持久化，可恢复、回放。
  • 界面：Web 图形界面或终端界面。
  • 设置与凭据：管理用户配置和 API Key。
  • 沙箱与审批：写文件、跑命令前可要求人工确认。

运行机制：一个轮次的旅程

  • 步骤 = 一次模型请求 + 它调用的工具。
  • 多个步骤组成一个轮次。
  • 轮次开始：领取输入、拼装提示词和工具清单，发给模型。
  • 模型决定调用工具则进入执行流水线，结果喂回模型，循环直到结束。
  • 事件驱动，每步持久化事件日志，模型看到的都能记录和回放。

与 Claude Code 的区别

  • Claude Code 像整车：开箱即用，但深度改装困难。
  • Harness 像底座加积木：开箱是毛坯，定制自由度极高。
  • 选型：快速干活选 Claude Code；深度定制、插件生态、CI 自动化选 Harness。

新手快速上手

  • 第一步：确认 Node.js 22+。
  • 第二步：终端运行 npx -y @deepseek-ai/dsh web，自动初始化。
  • 第三步：浏览器打开 127.0.0.1:3080，新建会话开始对话。
  • 一次性任务：dsh --profile headless “你好,用一句话介绍自己”。
  • 注意：当前 0.1.0-rc 预发布，可能有破坏性变更，生产谨慎。
