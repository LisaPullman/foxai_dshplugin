# 数字风洞 · 歼-35 舰载机（Web 3D Digital Wind Tunnel）

基于 `windtunnel-prompt-v2.md` 规格开发的交互式 Web 3D 数字风洞模拟器，模拟机型为 **歼-35 舰载机**（替代规格中的 F-35）。

> ⚠️ 本模拟采用**简化空气动力学模型**，仅用于**教育和可视化展示**，**不可用于真实飞行测试、工程认证或性能评估**。

## 特性

- **机型**：歼-35 舰载机程序化建模（无外部模型依赖）——双发锯齿喷口、DSI 无附面层隔道鼓包进气道、外倾约 25° 双垂尾、全动平尾（δe 联动偏转）、整体式金色无框座舱盖、舰载特征（弹射牵引杆 / 着舰尾钩 / 机翼折叠整流罩）
- **7 种可视化模式**：流线 / 烟线 / 粒子示踪（≤6 万粒子）/ 涡流（涡核螺旋 + 涡量着色）/ 表面压力云图 / 速度云图切片 / 纹影
- **物理**：ISA 分层大气（联动/独立切换）、涡格（马蹄涡）+ 势流 + 脱体涡 + 尾流/喷流 + 跨音速激波带、CL/CD/CY/Cm 查表拟合（含失速 / 波阻 / δe 修正）
- **10 个测试预设**、右侧 3 表盘 + 22 项实时参数、底部 6 联时间历程图表（20 Hz 采样，暂停/单步/清空）
- **交互**：单击机身局部参数探针（Cp/速度/涡量）、双击部件相机聚焦、悬停高亮 + 中英文说明、8 个相机预设 + 1s 平滑过渡、键盘快捷键（W/S/A/D/Q/E、1-7、R/C/H/F、Space）
- **性能**：流场分块烘焙至三维网格 + 三线性采样，桌面 60 FPS；分辨率倍率 / 抗锯齿 / 阴影 / 帧率限制可调
- **中英文双语**、可选风洞噪声（WebAudio）、免责声明常驻底部

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5188
npm run build    # 产物输出至 dist/
npm run preview  # 预览构建产物 http://localhost:5189
```

纯前端 SPA，无任何后端依赖。浏览器要求：Chrome/Edge 100+、Firefox 100+、Safari 16+（WebGL 2.0）。

## 工程结构

```
src/
├── main.js          # 入口：渲染循环、事件编排、键盘
├── state.js         # 全局状态 + 机型数据 + 事件总线
├── i18n.js          # 中英文文案
├── presets.js       # 10 个测试预设
├── atmosphere.js    # ISA 大气 + 湍流
├── physics.js       # 气动系数（CL/CD/CY/力矩）
├── flowfield.js     # 解析流场（涡格/势流/激波）+ 网格烘焙
├── aircraft.js      # 歼-35 程序化建模（部件注册/LOD 基础）
├── tunnel.js        # 风洞场景（收缩段/测试段/扩散段/风扇/照明）
├── visualizers.js   # 7 种可视化模式
├── camera.js        # 相机预设 + 平滑过渡
├── gauges.js        # 圆弧表盘
├── charts.js        # 时间历程图表
├── picking.js       # 拾取探针/聚焦/悬停
├── sound.js         # 风洞噪声
└── styles.css       # 玻璃拟态暗色 UI
```

## 简化假设（UI 内标注）

不可压缩 / 低速可压缩 · 无粘性主导分离预测 · 忽略机身弹性形变 · 忽略发动机进气畸变。机型几何参数取自公开资料外观估算，仅示意外形，不展示任何内部结构或武器系统。
